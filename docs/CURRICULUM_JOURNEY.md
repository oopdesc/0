# 一問から、2,098問へ

入口は `/learn?section=journey` です。通常問題、補充問題、試験からの練習、従来のブラウザ演習を、重複を除いた一つの道でたどれます。問題の本文・解説・採点条件を新しく複製せず、それぞれの教材から読み込みます。

## 道とレベルの違い

「ステップ」はおすすめの順序、「レベル」は完了した別々の問題の数です。途中から始めてもよく、正答するとレベルが1上がります。同じ問題への再挑戦や別形式で数を水増ししません。レベルは学習記録で、資格や技能認定ではありません。

- 初級から上級へ進む順を基本に、導入する概念と前提の情報から順序を組みます。既知の前提に循環があれば生成を止めます。
- Java・Rustを絞って眺めたり、ステップ番号で移動したりできます。ロックはありません。
- 試験の問題をこの道で解いても、時間制限のある試験の得点や合否には加算しません。
- 記述の自己確認を、コンパイラでの合格に変換しません。公開サーバーで任意コードを実行しません。

## 記録

`0.journey.progress.v1` に問題のID、確認日時、確認の種類を保存します。通常の正答、手がかり付きの正答、固定テストによる確認、自分で確認した完了を区別します。取り込みは既存記録との統合です。不正な保存データを黙って全置換しません。

通常問題集、補充問題集、従来の演習、時間制限のある試験の保存領域は残しています。以前の正答を、新しいカリキュラムの全問合格として一括変換することはしません。カリキュラムの記録は詳細欄から書き出せます。

## 更新時

1. `npm --prefix web run stats` で問題の同一性と順序を再生成します。
2. `npm --prefix web test` で全問の被覆、前提の順序、重複しない加算、壊れた保存データの保護を検査します。
3. 実画面で各出典の問題と、次・前・移動・保存を確認します。

件数や順序の機械検査は、全設問の教育的な質や、全学習者に一切のつまずきがないことの証明ではありません。教材は問題ごとの根拠と解説を読みながら改善できます。
