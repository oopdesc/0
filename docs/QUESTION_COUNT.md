# 問題数の集計

トップに表示する合計は、通常問題集・コード記述・補充問題集・試験・旧ブラウザ演習を合わせた数です。記述問題は合計の内数です。JavaとRustを比較する設問は、教材が指定する主言語に一度だけ数えます。試験の本数、実験、制作課題のミッション数を足していません。

ビルド時に、公開されている問題と、試験に採用された設問だけを読み直します。下書きや利用者の学習記録を集計に使うことはありません。

1. 同じ元の問題IDを使った再掲をまとめます。試験の `reusedFrom` と、旧教材から引き継いだIDもたどります。
2. 同じ言語・回答形式で、設問・コード・選択肢が同じものをまとめます。選択肢の並び順は数の違いにしません。記述では解答と固定テストも照合します。
3. 出力やコンパイル結果を予測する問題では、同じコードと回答を使った再掲もまとめます。コードの整形とコメントの違いは除き、引用符内の文字列は変えません。
4. 同じ分野や概念を扱うだけで、別の問題を重複として捨てることはしません。

これは公開データの元IDと内容に基づく再現可能な集計です。意味が似ているすべての問題を数学的に同一と証明するものではありません。教材の閲覧場所や既存の学習記録は変えず、件数だけで同じ問題を何度も加算しないために使います。

内訳はトップの「問題数の内訳」で開けます。通常問題を優先し、そこにない補充問題、試験問題、旧ブラウザ演習の順に追加分を集計しています。各問題集の一覧に出る掲載件数とは異なります。

「全問題から探す」では、この合計の各設問を一度ずつ表示します。問題名・分野・IDを検索し、言語・難しさ・記述・教材で絞り、元の問題へ直接進めます。試験だけの設問は、該当する試験のその問題を開きます。通常問題の表示と記述版が別の教材にある場合は、記述版のリンクも残しています。解答は索引に含めず、選んだ教材の画面で確認できます。

```sh
npm --prefix web run stats
npm --prefix web test
```

集計元は `web/tools/learning-inventory.ts`、照合規則は `question-identity.ts` です。結果は `web/src/generated/learning-stats.json` に生成され、トップと学習の入口で共有します。
