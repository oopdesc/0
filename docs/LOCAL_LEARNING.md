# 手元でJava・Rustのコードを実行する

公開サイトでは予測問題・解説・下書き・復習が使えます。入力したJavaやRustをサーバーへ送って実行する機能はありません。

自分のMacでは、同じ画面からJDKとrustcを使って固定テストを実行できます。

1. ソースを開き、JDK 21、Node.js 24、Rustを用意します。
2. リポジトリのディレクトリで `./tools/portfolio.sh local-learning` を実行します。
3. 表示される `http://127.0.0.1:18423/learn?section=writing&lang=java` を開きます。
4. JavaまたはRustの課題を選び、コードを書いて「このコードを手元でテストする」を押します。
5. 結果と入力・境界ケースを見比べます。コードを編集すると、その結果は未実行に戻ります。

Eclipseからは、`Portfolio_Web` プロジェクト内の `.launch/Portfolio — JavaとRustの実行演習.launch` を外部ツールとして実行できます。開発サーバーだけが必要なら、従来の「Webを起動」を使ってください。JavaのデバッグはJavaプロジェクト側、ブラウザの画面のデバッグはブラウザの開発者ツール側で行います。

終了は実行中のコンソールで停止するか、TerminalでCtrl+Cです。自動起動・外部公開はしません。

採点には正解例との文字列一致を使いません。編集したソースを実際にコンパイルし、固定ハーネスの入力ごとに標準出力・終了状態を照合します。有限のテストに通ったことは、全入力での正しさの証明とは異なります。

この機能は完全なOSサンドボックスではありません。自分で書いた信頼できるコードだけを実行してください。待ち時間・出力・同時実行数は制限しますが、未知のコードの安全性を保証するものではありません。公開サイトから訪問者のlocalhostへ接続する機能や、有料コンパイルAPIは使いません。

実際のHTTPとDBまで学ぶ題材は `backend/java-learning-v2`（Java / H2）、`projects/java/book-api-http`（Java / JDBC / SQLite）、`projects/rust/book-api-http`（Rust / SQLite）にあります。会社のDB接続情報は不要です。
