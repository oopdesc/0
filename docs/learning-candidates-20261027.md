# 学習サイトの比較と採用範囲

2026年10月27日。ファイル名の1〜5を基準に比較。モデル名は成果物から確認できないため評価に使っていません。ZIPの重複や梱包違いは別サイトとして加点していません。

## 総合順位

|順位|候補|判断の理由|注意点|
|---|---|---|---|
|1|5番系|109問版は付属92テスト成功。JavaのTeaVMとRustのWasmで固定問題を実行でき、予測・理由・再現・類題がつながる。別の1,397問版は検索・復習・概念マップが充実。|大規模版には不整合がある。問題数だけで品質を判断できない。|
|2|3番・103問版|教材、処理追跡、出典、類題の構成がまとまり、読みやすい。付属テスト59/60成功。|復習優先順位のテストが1件失敗。未修正のまま丸ごと公開しない。|
|3|1番・ORBIT|デザインでは最上位。軌道を操作し、コードの変更を模型で確認する流れが自然。6題を7段階で掘り下げる。|大規模問題集ではない。実行器は限定された教材用で、汎用JVM/rustcではない。|
|4|2番系・103問版|明るい画面、学習履歴、予測から復習までの基本構成が分かりやすい。|負数の剰余の説明に明確な誤り。「除数の符号」ではなく、Javaでは剰余は被除数側の符号。画面の言語別件数にも差がある。|
|5|4番・140問版|問題の種類と類題が多く、宇宙の独立モジュールを持つ。|原本のルーターが常にNotFoundを選び、トップ画面も開けない。まず入口の修理が必要。原本状態ではデザインの比較条件が成立しない。|

これは「このまま学習に使いやすいか」を重視した総合順位です。全問の正解を人手で精査した順位ではありません。見た目だけならORBITを第一候補にし、3番のまとまり、5番の教材UIを用途に応じて使います。

## 今回の統合

- 既存の探索・宇宙・Java API・Rust Wasm・Eclipse入口を保持。
- ORBITの6実験と操作可能な宇宙模型を遅延読み込みで追加。
- 5番109問版の予測・実行・再現・復習を追加。固定Java/Rust問題用の実行モジュールも同梱。
- 5番大規模版から、付属コンパイラ記録と期待値・概念参照が一致した1,147問を収録。250問は保留。対話型採点をさらに精査する必要がある問題も保留に含む。
- 「全問をこのMacで実コンパイラ検証した」とは主張しない。1,147問は提供物の付属記録を照合したもので、今回全問を再コンパイルしたものではない。
- 教材同士に似たテーマがあるため、合計を「重複のないユニーク問題数」とは表示しない。
- 保留問題と原本はローカル監査フォルダへ保持。既知の誤りを無条件に問題集へ足していない。

## 公開前の容量確認

Hobbyプランを実画面で確認。転送278.5MB/100GB、Deployment Storage 402.6MB/10GB（確認時）。追加の契約・DB・API・サーバー関数は作成しない。

統合後の静的ファイル約22.3MB、初回JavaScript約83KB gzip。問題集等を全部合わせたJSは約911KB gzip。従来の全JS512KiB予算は大規模問題集の追加に合わせ1MiBへ改定し、初回JS128KiBと静的30MiBの上限を別々に検査する。これは内部の品質予算で、Vercelの課金上限ではない。

将来のアクセス数を予測して無料枠内を無条件に保証することはできない。今回の公開は確認時の使用量・Hobbyプラン・静的構成の範囲で行う。新しいVercelプロジェクトは作成しない。
