# 星雲の中へ

トップは「星雲の奥へ」と同じ描画エンジンを使っています。ゆっくり回る球面を内側から眺め、手前の星と細い光の線を重ねます。写真を拡大して動かす仕組みではありません。天体観測や、星の形成を計算した科学シミュレーションとは区別してください。

## コードをたどる

1. [HomeNebula.tsx](../web/src/art/HomeNebula.tsx) が表示と操作を受け持ちます。
2. [renderer.ts](../web/src/art/nursery/renderer.ts) が、共通エンジンへトップ用の設定を渡します。
3. [nebula/scene.ts](../web/src/art/nebula/scene.ts) が球面の雲、点、点を結ぶ線、淡い光を描きます。球面上の向きに対して、大きさを変えたノイズを重ねています。星の点は三次元空間を動き、近くの点を空間の格子で探して線を結びます。
4. [far-stars.ts](../web/src/art/nebula/far-stars.ts) が遠景の星を置きます。「天の川の内側」では、広い星空に加え、傾いた帯の周囲へ星を集めます。実測の天の川の星表ではありません。

トップでは、元の作品より点を小さく、発光を弱くしています。点が広い範囲へ流れ、線がほどけていくようにしています。球面の自動回転に加え、ドラッグで周囲360度を見渡せます。拡大・縮小とキーボードの操作も利用できます。

## 自分で変えて確かめる

- `homeVariant` の点の大きさ・発生数を一つだけ変えて、線の読み取りやすさを比べます。粒子や描画上限を増やす必要はありません。
- `autoRotateSpeed` を少し変え、星と雲の位置関係がどのように変わるか観察します。
- `nebulaMat` の `cool` と `warm` を変え、光が強いことと、色の差が大きいことを比べます。
- `far-stars.ts` で星の帯の傾きを変えます。画像を回転することと、球面の内側から視線を変えることの違いを確かめます。

## 背景・全画面

各作品の「全画面で見る」で作品だけを眺められます。対応する端末では「端末の全画面」も使えます。背景設定からは、すべてのページ、または今のページだけを選べます。文字を載せる領域は読みやすい面を残し、背景の濃さは別に調整します。

- トップの動く作品を表示している間、その背後の背景作品は静止します。スクロールしてトップの作品が画面外になれば背景の動きへ戻ります。
- 全画面では元の作品を止め、選んだ作品だけを動かします。
- トップは上限24fps・70万描画画素、背景の星雲は上限15fps・50万画素です。全画面の既存星雲は上限24fps・85万画素です。
- 画面外・別タブ・停止中・端末の「動きを減らす」設定では連続描画を止めます。
- 設定はブラウザ内に保存します。アカウント登録、追加のサーバー、API課金は使いません。
