# 無料枠での配信と容量の確認

2026年10月28日確認。既存の `0-3gaz` だけへ、静的ファイルを配信します。新しいVercelプロジェクト、常駐API、有料DB、AI APIは追加しません。

## 月間転送量と、ファイルの容量は別です

HobbyのFast Data Transferは月100GB、Fast Origin Transferは月10GB、CDN Requestsは月100万回です。100GBを日数倍して使えるわけではありません。Hobbyは個人・非商用向けで、通常は超過した機能が利用停止になり、再開まで待つ必要があります。アップグレードは行いません。[Vercel公式：Hobby](https://vercel.com/docs/plans/hobby)

CDNから閲覧者へ送るデータも転送量に含まれます。CDNのキャッシュがあっても、閲覧者への配信が無制限になるわけではありません。[Vercel公式：CDNの使用量](https://vercel.com/docs/manage-cdn-usage)

このサイトの宇宙模型は閲覧者のブラウザで描画します。毎フレームの映像をサーバーから配信する仕組みではありません。必要なコードや画像・動画を読み込む際には転送が発生します。

## 今回の静的成果物

- 全静的ファイル：約22.4MB。リポジトリ内の検査上限は30MiBです。
- 初回JavaScript：約84.5KB gzip。静的なimport先まで含めて測ります。
- トップのHTML/CSS/JavaScript：約102KB gzip推計。
- 問題集を開くまでのHTML/CSS/JavaScript：約613KB gzip推計。
- 星雲の描画コードまで：約248KB gzip推計。
- 作品は選んだものだけ起動し、離れると描画資源を解放します。
- 観測資料の動画は自動再生せず、再生を押した場合だけ読み込みます。

上の推計はビルドの依存関係から算出したもので、実通信量の測定ではありません。HTTPヘッダー、後から選ぶ資料・画像・動画、画面操作に伴う追加読込は含みません。正確な値はVercel Usageで確認します。最新の機械判定結果はビルド後の `web/release-report.json` に出力します。

Hobbyの静的アップロード上限は100MBです。配信するものはビルド済みファイルだけで、原本ZIP、node_modules、比較用候補、バックアップは含めません。[Vercel公式：Limits](https://vercel.com/docs/limits)

## アクセスが増えたときの目安

月間転送量 ≒ 訪問回数 × 1訪問あたりの平均転送量。ブラウザキャッシュ、閲覧ページ、動画の再生、ボットで変わります。

100GBのうち20GBを余裕として残し、80GBで考える単純な例です。1GB＝1,000MBとして概算しています。

|1訪問の平均転送量|月間訪問数の目安|30日で割った1日平均|
|---|---:|---:|
|1MB|80,000回|約2,666回|
|3MB|約26,666回|約888回|
|10MB|8,000回|約266回|
|25MB|3,200回|約106回|

同じアカウント内の他プロジェクトの利用やCDNリクエスト数も影響します。この表は上限を保証するものではありません。

## 更新時の確認

1. `./tools/portfolio.sh verify` でJava/Rust/Web・公開内容・容量を確認する。
2. VercelのプランがHobbyであること、Usageの転送量・リクエスト・保存量を確認する。
3. 既存プロジェクトだけを更新し、公開後の画面とDeployment成功を確認する。
4. 利用量が増えたら、まず動画の配信や不要な再読込を減らす。課金プランへの変更はしない。

将来のアクセス数やVercelの仕様変更まで「絶対に超えない」とは断定できません。無料プランを維持しながら、容量検査と実使用量を分けて確認します。
